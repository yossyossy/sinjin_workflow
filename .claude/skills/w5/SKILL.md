# W5｜確定後の記録（5分）

案件完了後、**外した仮説だけ**を記録する。当たった仮説は成果物に吸収されるので不要。

## 手順

1. `W3_仕分け.md` の仮説のうち、W4のやり取りやその後の実装で外れたと分かったものを洗い出す。
2. `W5_記録.md` の表に追記する。4列目（実際の理由）が本体。「現場が変だ」で終わらせず、「自分が知らない制約が効いていた」に変換する。
3. W0の認識ズレ（あれば）、説明できなかった既存実績（先輩が「分からない」と返したもの）も記録する。
4. `python scripts/wf_lint.py W5` を実行。
5. 記録が確定したら `python scripts/wf_archive.py` で `knowledge/制約カタログ.md` に集約し、案件を完了扱いにする。

## 完了条件

案件が完了扱いになり、`cases/.current` の指定が外れる。次の案件は `/wf-new` から。
