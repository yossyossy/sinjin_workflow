# W2｜並べる（20〜30分）

W1が未記入だとハーネスの hook がこの工程のファイル作成をブロックする。先にW1を終わらせること。

## 手順

1. 作業中の案件の `W1_先出し.md` と `W2_並べる.md` を開く。
2. **比較対象を3つ以上**（現場の実績／外部の実績／障害・変更履歴）集めるようユーザーと一緒に探す。2つ（対比）で止めない。
3. W1の案と各比較対象の**差分を列挙する。判定しない。**
   - NG例：「実物の方が良い」「〜べき」「〜が正しい」
   - OK例：「実物はA方式、W1案はB方式」
4. 各差分を `なぜ X であって Y ではないのか` の形に変換する。この形にならない差分は保留し、次に進めない。
5. AIを使ってよい箇所（プロンプト例）：
   - 差分列挙：「以下2つの方針の差分を列挙して。どちらが良いかの判定は不要」
   - 問いの量産：「この構成について『なぜXでYでないのか』形式の問いを10個」
   - 対抗仮説：「この設計になる理由として一般的にあり得るものを、確度に関わらず全部」
   - 誤読チェック：「この文章から読み取れる内容だけを再構成して」（ユーザー自身が書いた文を渡す）
6. **AIが生成した記述は行頭に `[AI]` を付けて書き込む。** W3で「確認済み」に混入させないための目印。
7. `python scripts/wf_lint.py W2` を実行し結果を見せる。

## やってはいけないこと

- 差分に良し悪しの判定を書く（「実物が正しい」と書いた時点でこの工程は失敗）
- AIに現場固有の理由を断定させる（一般論の提示までは可、断定は不可）

## 完了条件

`python scripts/wf_lint.py W2` が error 0件。次は `/w3`。
