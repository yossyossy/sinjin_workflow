# wf-new｜案件の立ち上げ

ユーザーが新しい案件（作業指示）を受け取った直後に使う。「新しい案件を始めたい」「〇〇の案件を立ち上げて」等で起動する。

## 手順

1. ユーザーに案件名・期限（分かれば）・指示文の原文（メール/チケット/議事録のコピペで可）を尋ねる。指示文が今すぐ無ければ空でもよい。
2. 次を実行する。

```
python scripts/wf_new.py "<案件名>" [--due YYYY-MM-DD] [--owner <担当>]
```

3. `cases/<日付>_<案件名>/指示文.md` を開き、ユーザーから受け取った指示文の原文をそのまま貼る（要約しない。転記チェックがこの原文と突き合わせて動くため、原文である必要がある）。
4. 作成後、次に行うのは **W0** であることを伝える。`/w0` を促す。

## 禁止事項

- ここで要件を埋めない。埋めるのはW0の役目。
- 指示文を自分の言葉に直して貼らない。原文のまま。
