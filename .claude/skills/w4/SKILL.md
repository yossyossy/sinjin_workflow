# W4｜レビュー依頼（先輩の関与点）

想定応答時間 5〜15分。**「未解明」だけを持ち込む。** AIで解けたものは持ち込まない。

## 手順

1. `W3_仕分け.md` の「未解明」と `W4_レビュー依頼.md` を開く。
2. 確認したいことは必ず「〜と推測しましたが合っていますか」の形で書く。「教えてください」「どうすればいいですか」等の**手段そのものを聞く文はNG**（返答がそのまま自分の案になり、以降の工程が空回りする）。
3. 「採らなかった案と理由」を必ず埋める。採用案だけでは後から判断根拠を復元できない。
4. `python scripts/wf_lint.py W4` を実行。手段質問・推測なし質問・空欄をここで検出する。
5. 完成した依頼文をユーザーに提示する。**実際に先輩へ送る／伝えるのはユーザー。**
6. 先輩からの回答を受け取ったら、`W3_仕分け.md` の該当仮説を確定させ（合っていれば確認済みへ、外れていれば理由とともにW5の材料にする）、`W5_記録.md` に外れた仮説を記録するようユーザーに促す。
