# W3｜仕分け（15分）— この3分割が手順の中核

AIの生成物は断定文で出る。転記の過程で「〜と考えられます」が「〜です」に変わり、そこから先は誰も検証しない。**注意力ではなく様式で防ぐ**のがこの工程。

## 手順

1. `W2_並べる.md` の内容（問い・`[AI]` 付き記述含む）と `W3_仕分け.md` を開く。
2. 各項目を3つに仕分ける：
   - **確認済み**：一次情報・当事者の発言・ドキュメント明記のみ。**`[AI]` 印が付いた記述は絶対にここに入れない。**
   - **仮説**：内容・根拠・確度（高/中/低）・反証条件（もし〜が事実なら成り立たない）・外れた場合に変わること・**対抗仮説**を全て埋める。対抗仮説が無い仮説は「最初に思いついただけ」なので、AIに「この設計になる理由として一般的にあり得るものを全部」出させて対抗案を作る。
   - **未解明**：AIで解消せず、現場固有の可能性が高いもの。**ここに挙げたものだけがW4に持ち込まれる。**
3. 仮説は断定形で書かない（「〜と推測する」「〜の可能性がある」の形）。リンタが断定文を検出する。
4. `python scripts/wf_lint.py W3` を実行。特に次を確認：
   - 対抗仮説の欠落
   - 反証条件の欠落（**仮説の質は確認の安さで測れる**）
   - 未解明が0件（疑問が出てこなくなると全部が推測のまま実装まで通る、危険信号）

## 完了条件

`python scripts/wf_lint.py W3` が error 0件。次は `/w4`。
